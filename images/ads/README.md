# Picha za matangazo ya ML Christian Radio

Pakia picha zako katika folda hii ili zionekane kwenye carousel ya ukurasa wa mwanzo.

Majina yanayotumika kwa sasa:
- `advert-1.jpg`
- `advert-2.jpg`
- `advert-3.jpg`

## Jinsi ya kuweka picha
1. Fungua repository ya GitHub: https://github.com/mwakapalilamedia-ops/ML-Christian-Radio--home-of-champions-
2. Bonyeza **Add file** kisha **Upload files**.
3. Chagua picha ya tangazo kutoka kwenye simu au kompyuta.
4. Hakikisha jina lake ni mojawapo ya majina hapo juu, kwa mfano `advert-1.jpg`.
5. Pakia kwenye folda `images/ads/`. Ikiwa GitHub haikuonyeshi folda, tumia **Add file → Create new file** na uandike `images/ads/README.md` ili kuunda folda kwanza.
6. Bonyeza **Commit changes**.
7. Subiri GitHub Pages isasishwe, kisha fungua tovuti upya.

Inapendekezwa kutumia picha za JPG au PNG zenye upana wa angalau pikseli 1200. Picha hubadilika kiotomatiki kila sekunde 5.
